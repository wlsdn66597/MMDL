# MMMU-Pro 10지선다 평가 · 기본 모델과 DPO2-E 비교

**DPO2-E는 MMMU-Pro test 1,730문항에서 54.68%를 기록했다. 기본 모델의 52.60%보다 36문항, 2.08%p 높았다.** 반복 생성 조기 중단은 175건에서 7건으로 줄었다.

- **전체**에서 기존 오답 165문항을 새로 맞혔고, 기존 정답 129문항을 틀렸다. 순증은 36문항이다.
- **기본 모델이 반복 생성으로 중단된 175문항** 중 DPO2-E는 169문항을 정상 종료했고, 그중 63문항을 맞혔다. 해당 175문항에서 얻은 순증은 63문항이다.
- **두 모델 모두 정상 종료한 1,551문항**에서는 기본 모델 910문항, DPO2-E 882문항을 맞혔다. 101문항은 정답으로 바뀌었고 129문항은 오답으로 바뀌어 순감은 28문항이다.
- 전체 평균 출력은 767.5토큰 줄었다. 정상 종료 출력의 평균은 기본 모델 1,627.2토큰, DPO2-E 2,116.4토큰이었다. 이 두 평균에는 모델마다 서로 다른 문항이 포함된다.

전체 점수 상승은 주로 기본 모델이 반복 생성으로 중단했던 문항에서 나왔다. 결과는 두 모델을 각 한 번씩 실행해 얻은 값이다.
